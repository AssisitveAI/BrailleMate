# BrailleMate 개인정보처리방침

**시행일: 2024년 4월 1일**

KAIST AAI Lab(이하 "개발자")은 BrailleMate(이하 "앱") 이용자의 개인정보를 중요시하며, 「개인정보 보호법」 등 관련 법령을 준수합니다.

## 1. 수집하는 개인정보 항목

본 앱은 **개인정보를 수집하지 않습니다.**

### 앱이 처리하는 데이터

| 데이터 유형 | 저장 위치 | 서버 전송 여부 |
|-------------|-----------|----------------|
| AI 대화 내용 | 사용자 기기 내부 (로컬) | ❌ 전송 안 함 |
| 북마크 정보 | 사용자 기기 내부 (로컬) | ❌ 전송 안 함 |
| Gemini API 키 | 사용자 기기 내부 (로컬) | ❌ 전송 안 함 |
| 점자 규정 검색 기록 | 사용자 기기 내부 (로컬) | ❌ 전송 안 함 |

## 2. AI 기능 관련 안내

- 본 앱은 Google Gemini API를 활용한 AI 점자 컨설팅 기능을 제공합니다.
- AI 기능 사용 시 사용자가 입력한 질문 내용이 Google Gemini API 서버로 전송됩니다.
- 전송되는 데이터는 사용자가 직접 입력한 **질문 텍스트**에 한정되며, 개인 식별 정보는 포함되지 않습니다.
- Google의 데이터 처리에 관해서는 [Google의 개인정보처리방침](https://policies.google.com/privacy)을 참고해 주세요.
- AI 기능은 사용자가 직접 발급한 API 키를 사용하며, 개발자는 API 키에 접근하지 않습니다.

## 3. 오프라인 기능

- 점자 규정 레퍼런스 기능은 인터넷 연결 없이 완전히 오프라인으로 작동합니다.
- 오프라인 기능 사용 시 어떠한 데이터도 외부로 전송되지 않습니다.

## 4. 데이터 보관 및 삭제

- 모든 앱 데이터는 사용자의 기기에만 저장됩니다.
- 앱을 삭제하면 모든 데이터가 자동으로 삭제됩니다.
- 설정 화면에서 대화 기록 및 북마크를 직접 삭제할 수 있습니다.

## 5. 제3자 제공

본 앱은 사용자의 개인정보를 제3자에게 제공하지 않습니다.

## 6. 아동의 개인정보 보호

본 앱은 만 13세 미만 아동의 개인정보를 별도로 수집하지 않습니다. 본 앱은 교육 목적의 레퍼런스 앱으로, 모든 연령이 사용할 수 있습니다.

## 7. 개인정보처리방침의 변경

본 방침이 변경되는 경우 앱 업데이트를 통해 공지합니다.

# BrailleMate — Google Play Store 등록 정보

## 앱 이름
BrailleMate - AI 점자 컨설팅

## 간단한 설명 (80자 이내)
2024 한국 점자 규정 검색 + AI 점자 컨설팅. 점역교정사·점자 학습자 필수 앱.

## 자세한 설명

점역교정사와 점자 학습자를 위한 최고의 도우미, BrailleMate!

📖 2024 한국 점자 규정 전문 수록
문화체육관광부고시 제2024-0005호에 따른 최신 개정 한국 점자 규정 전문을 담았습니다.
• 한글 점자 (자모, 약자, 약어, 문장 부호)
• 수학 점자 (수식, 기하, 함수, 미적분, 통계)
• 과학 점자
• 한국 음악 점자 (정간보, 오선보)
• 서양 음악 점자
• 외국어 점자 (9개 언어)
• 국제음성기호(IPA) 점자

🔍 강력한 검색 기능
조항 번호, 키워드, 예시 단어로 필요한 규정을 즉시 찾으세요. 전문검색(Full-Text Search)으로 정확하고 빠른 결과를 제공합니다.

🤖 AI 점자 컨설팅
"쌍시옷은 점자로 어떻게 적나요?"처럼 자연어로 질문하면, AI가 관련 규정 조항을 인용하며 정확한 답변을 제공합니다.
• 해당 규정 조항 자동 인용
• 점자 표기 예시 제공
• 대화 기록 저장

📴 오프라인 완벽 지원
규정 검색과 북마크 기능은 인터넷 없이도 완벽하게 작동합니다. 현장에서도 언제든 규정을 확인하세요.

⭐ 주요 기능
✓ 265개 조항 전문 수록 (2024 개정판)
✓ 계층적 목차 탐색 (대분류 → 장 → 절 → 항)
✓ FTS 기반 전문검색
✓ AI 점자 전문 컨설팅 (Google Gemini 기반)
✓ 북마크 기능
✓ 다크 모드 지원
✓ TalkBack 접근성 지원
✓ 점자 6점 시각화

💡 이런 분들에게 추천합니다
• 점역교정사 자격시험 준비생
• 현직 점역교정사
• 시각장애인 교육 관련 종사자
• 점자를 배우고 싶은 모든 분

※ AI 컨설팅 기능은 사용자의 Google Gemini API 키가 필요합니다.
앱 설정에서 무료로 발급받은 API 키를 입력하면 바로 사용할 수 있습니다.
